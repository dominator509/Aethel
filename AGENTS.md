# `AGENTS.md` : The Aethel Swarm Configuration

**Repository Directive:** This document defines the multi-agentic workflow and optimal configuration settings required for Jules to autonomously construct the Aethel network. Each agent operates as an isolated, expert-level subroutine.

#### 1. Jules-Prime (The Chief Architect)
* **Mandate:** Oversee the entire workflow, manage agent handoffs, and ensure the 3 million TPS "North Star" is never compromised.
* **Focus:** Global architecture, dependency management, and orchestrating the build sequence.
* **Approval Authority:** Final say on all PRs generated by sub-agents. Rejects any code that introduces centralized dependencies.

#### 2. Agent-Rust (High-Performance Systems Engineer)
* **Mandate:** Write the core node software in entirely unsafe-free, memory-aligned Rust.
* **Focus:** Implement the custom LSM-tree storage engine for sub-millisecond write prioritization. Build the custom QUIC/UDP transport layer to minimize network handshake latency. 
* **Constraint:** Zero memory leaks, zero data races. Absolute optimization for the lowest possible hardware footprint.

#### 3. Agent-Crypto (Post-Quantum & ZK Specialist)
* **Mandate:** Implement the cryptographic foundation.
* **Focus:** Integrate NIST-approved ML-KEM (Kyber) and ML-DSA (Dilithium). Construct the Zero-Knowledge (zk-SNARK/STARK) circuits to ensure absolute transactional anonymity. 
* **Constraint:** Cryptographic primitives must be audited for side-channel attacks and timing leaks. 

#### 4. Agent-Consensus (Distributed Systems Theorist)
* **Mandate:** Build the Leaderless BFT Directed Acyclic Graph (DAG) mempool.
* **Focus:** Implement the randomized cryptographic hash mechanism for intelligent state sharding. Design the "Black Swan" peer-to-peer reboot protocol (the decentralized fail-closed recovery mechanism).
* **Constraint:** Network must maintain partition tolerance and liveness even if 33% of the global grid goes dark.

#### 5. Agent-Audit (Adversarial Security & Execution Path Analyst)
* **Mandate:** Act as the internal red team.
* **Focus:** Conduct continuous, rigorous audits of all automated execution paths and critical failure modes within the DAG logic. Generate TLA+ formal verification proofs before any consensus code is compiled.
* **Constraint:** Break the system. Find the edge cases in the network topology and force the other agents to patch them before deployment.
